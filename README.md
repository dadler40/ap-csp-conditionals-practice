# AP CSP: Conditionals & Boolean Logic Practice

A collection of "Agree or Disagree" debugging questions modeled after **Code.org AP Computer Science Principles (Unit 4, Lesson 5: Conditionals Explore)**, alongside curated AP CSP exam practice resources.

**For study use:** every answer is included (collapsed, in the quiz file; printed after each question, in the terminal script). Use this set to practice and self-check — it is not a graded assessment.

## Contents
- [`conditionals-quiz.md`](./conditionals-quiz.md) — 11 compound boolean debugging problems (warm-up + 10 questions) with expandable answers and explanations.
- [`quiz.py`](./quiz.py) — Interactive command-line version of the same 11 questions.

## A note on syntax
The questions are written in the JavaScript style used in Code.org's App Lab (`&&`, `||`, `!`, `==`), because that is where you write code in class. Each question also shows the **AP exam pseudocode** version from the College Board reference sheet, which writes the same ideas with `AND`, `OR`, `NOT` and the symbols `=`, `≠`, `≥`, `≤`. The logic is identical — only the spelling changes. On exam day, expect the pseudocode spelling.
